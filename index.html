No.03

使い分け実験ノート

同じスパイスでも「いつ・どんな形で入れるか」で仕上がりは別物になります。スパイスカレー作りで差がつく4つのポイントをまとめました。

テンパリングの流れを、ひと目で

1
油を温める煙が出る手前まで

熱しすぎると香りが飛んで苦みに。弱めの中火が安全圏。

2
ホールスパイスを入れる約30秒

クミンは色が少し濃くなったら、マスタードはパチパチ跳ね終わったら合図。

3
具材を加えて香りをまとう

玉ねぎや豆に香りの油を絡める。ここからがカレーの土台づくり。

4
仕上げは火を止めてから

ガラムマサラと挽きたてペッパーは最後。揮発する香りを逃がさない。

テンパリング（油に香りを移す）

ホールスパイスの香り成分の多くは脂溶性。水ではなく油に溶け出して、料理全体へ広がります。だからカレーは「油＋ホールスパイス」から始めるのが基本形です。

  • 油は煙が出るほど熱くしない。高温すぎると香りが飛び、苦みが出ます
  • クミンシードは色がほんの少し濃くなり、香りが立ったら次の工程へ。30秒前後が目安
  • マスタードシードはパチパチ跳ね終わるまで待つ。跳ねる前に具材を入れると青臭さが残ります
  • 蓋をすると香りが戻るので、跳ねる系は小さな蓋や油はね防止ネットがあると安心

入れるタイミング早見表

最初

ホールスパイス（クミンシード、カルダモン、クローブなど）。油に香りを移す“香りの土台”づくり。

中盤

パウダースパイス（ターメリック、コリアンダー、クミンパウダー）。玉ねぎ・トマトの水分があるうちに入れると焦げにくい。

終盤

チリパウダーは色と辛さの調整に。煮込みすぎると色がくすむので、仕上がりを見ながら。

仕上げ

ガラムマサラと挽きたてブラックペッパー。香りが揮発しやすいので、火を止める直前〜直後が勝負。

合言葉は「ホールは先、パウダーは後、マサラは最後」。これだけで香りの層がぐっと深くなります。

シード vs パウダー、どっちを買う？

クミンのように両方の形があるスパイスは、役割がまったく違います。

  • シード（ホール）：香りが長持ちし、テンパリングで“立ち上がる香り”を担当。買ってから1年ほど楽しめます
  • パウダー：味と香りが料理に馴染む“広がる香り”担当。ただし表面積が大きく酸化が早いので、開封後は1〜2か月で使い切りたいところ
  • 余裕があればホールで買って、使う分だけミルや乳鉢で挽くのが最強。挽きたての香りは別格です
  • 保存は共通で遮光・密閉・常温の涼しい場所。冷蔵庫は結露と他の食品の匂い移りに注意

焦がすとどうなる？ 苦みの境界線

スパイスの「香ばしさ」と「苦み」は紙一重。種類ごとに焦げやすさが違います。

  • フェヌグリークは最要注意。炒りすぎると一気に強い苦みへ。色づいたらすぐ引き上げます
  • パプリカとチリのパウダーは糖分を含むため焦げやすく、苦み＋色あせの原因に。必ず弱火＆水分のある場面で
  • クミンシードは乾煎りすると香りがナッティーに変化。焦げは「香ばしい」から「煙い」へ変わった瞬間が見極めどころ
  • 焦がしてしまったら、無理に使わず作り直すのが結果的に近道。苦みは後から消せません

Recipe 01 ・ 主菜

ひよこ豆のスパイスカレー

約30分 2〜3人分 辛さ調整OK

缶詰のひよこ豆を使えば煮込み時間は短くてOK。クミンを「シード」と「パウダー」で二度使いするのが、このレシピ一番のマニアポイントです。

材料

  • ひよこ豆（缶・水煮）1缶（約240g）
  • 玉ねぎ1個
  • トマト缶（カット）1/2缶
  • にんにく・生姜（すりおろし）各小さじ1
  • 油大さじ2
  • クミンシード小さじ1
  • クミンパウダー小さじ1
  • コリアンダーパウダー大さじ1
  • ターメリック小さじ1/2
  • チリパウダー小さじ1/4〜
  • 塩小さじ1弱
  • 水150ml
  • アムチュール（仕上げ・任意）小さじ1/2

作り方

  1. 玉ねぎは薄切りにする。ひよこ豆は缶の汁を切る（汁は取っておくと調整に使えます）。
  2. 鍋に油とクミンシードを入れて弱めの中火にかけ、香りが立って色が少し濃くなったら玉ねぎを加え、きつね色になるまで10分ほど炒める。
  3. にんにく・生姜を加えて1分炒め、パウダースパイス（クミン、コリアンダー、ターメリック、チリ）と塩を加えて弱火で30秒ほど炒める。
  4. トマト缶を加え、水分が飛んで油がにじむまで5分ほど煮詰める。これがカレーの“素”です。
  5. ひよこ豆と水を加えて弱火で10分煮る。味を見て塩とチリで調整し、あれば仕上げにガラムマサラひとつまみ。アムチュールを小さじ1/2ふると、爽やかな酸味で味が締まります。

使い分けのコツ：シードは最初の油で「立ち上がる香り」、パウダーは中盤で「味の芯」。同じクミンでも入れる場所で仕事が違います。チリは最後に足すほど色鮮やかに仕上がります。

Recipe 02 ・ 副菜

ジーラ・アルー（クミンポテト）

約20分 2人分 お弁当にも

インドの家庭の定番おかず。「ジーラ」はクミンのこと。じゃがいもと油とクミン、それだけでごはんが進む一品です。

材料

  • じゃがいも3個
  • 油大さじ1.5
  • クミンシード小さじ1
  • マスタードシード小さじ1/2
  • ターメリック小さじ1/3
  • チリパウダーひとつまみ
  • 塩小さじ1/2
  • レモン汁（仕上げ）小さじ1

作り方

  1. じゃがいもは皮をむいて1.5cm角に切り、水にさらして水気を切る。
  2. フライパンに油、マスタードシード、クミンシードを入れて中火にかける。パチパチ跳ねて香りが立ったらじゃがいもを加える。
  3. ターメリック、チリ、塩をふり、蓋をして弱火で10分ほど蒸し焼きに。途中で2〜3回返す。
  4. 竹串がすっと通ったら蓋を外し、中火で表面をカリッと焼く。火を止めてレモン汁を回しかける。

使い分けのコツ：マスタードシードは「跳ね終わるまで」が加熱完了のサイン。仕上げのレモンの酸で、油っぽさがすっと軽くなります。

Recipe 03 ・ ドリンク

ゴールデンミルク（ターメリックラテ）

約5分 1杯分 ノンカフェイン

鮮やかな黄色がかわいい、温かいミルクドリンク。夜のリラックスタイムにも。ブラックペッパーひとつまみが、実は科学的にも理にかなった相棒です。

材料

  • 牛乳または豆乳200ml
  • ターメリック小さじ1/2
  • シナモンパウダー小さじ1/4
  • カルダモンパウダーひとつまみ
  • ブラックペッパーひとつまみ
  • はちみつ小さじ1〜

作り方

  1. 小鍋にミルクとスパイスをすべて入れ、弱火にかけて混ぜながら温める。沸騰直前で火を止める。
  2. 茶こしでこすか、そのままカップに注ぐ。はちみつで甘さを調整する。
  3. お好みで表面にシナモンを少し振ると、見た目も香りもアップ。

マニアメモ：ターメリックの色素クルクミンは脂溶性で体に吸収されにくい成分ですが、ブラックペッパーのピペリンと一緒に摂ると吸収率が大きく上がるという研究報告で有名になりました。ミルクの脂肪分＋ペッパーの組み合わせは、まさにその条件に合っています。

Recipe 04 ・ ドリンク

おうちスパイスチャイ

約10分 2杯分 煮出し式

ホールスパイスを砕いて煮出す、本格派のマサラチャイ。エスプレッソショットを足せば、コーヒー好きにはたまらない「ダーティチャイ」にもなります。

材料

  • 水200ml
  • 牛乳200ml
  • 紅茶（アッサムなど）大さじ1.5
  • カルダモン4粒
  • シナモンスティック1/2本
  • クローブ3粒
  • ブラックペッパー4粒
  • 生姜（薄切り）2〜3枚
  • 砂糖大さじ1.5〜

作り方

  1. カルダモンは鞘に切れ目を入れるか軽く潰し、ペッパーとクローブも粗く砕く。
  2. 小鍋に水、スパイス、生姜を入れて火にかけ、沸騰したら弱火で3分煮出して香りを引き出す。
  3. 茶葉と砂糖を加えてさらに2分煮る。
  4. 牛乳を加え、沸騰直前に火を止める。一度沸き上がらせるとコクが出ますが、吹きこぼれに注意。
  5. 茶こしでこしてカップへ。甘さは最後にもう一度味を見て調整。

使い分けのコツ：カルダモンは鞘ごと使うと香りが穏やか、種だけ使うとシャープに。クローブは入れすぎると薬品っぽくなるので「3粒まで」が家庭での安全圏です。

Recipe 05 ・ 副菜

ベンガル風ミックスベジタブル

約25分 2人分 ホール5種使い

ベンガル地方の「パンチフォロン」＝5種のホールスパイスを丸ごと油で弾けさせる炒め煮です。新顔ニゲラのデビュー戦。じゃがいも、カリフラワー、かぼちゃ、いんげんと、甘みのある野菜がよく合います。

材料

  • じゃがいも2個
  • カリフラワー1/3個
  • かぼちゃ150g
  • いんげん6本
  • 油大さじ2
  • ニゲラ小さじ1/2
  • フェンネルシード小さじ1/2
  • マスタードシード小さじ1/2
  • クミンシード小さじ1/2
  • フェヌグリーク小さじ1/4
  • ターメリック小さじ1/3
  • チリパウダーひとつまみ
  • 塩小さじ1/2
  • 砂糖ひとつまみ

作り方

  1. 野菜はすべて一口大に切る。じゃがいもは水にさらして水気を切る。
  2. フライパンに油と5種のホールスパイスをすべて入れて中火にかける。マスタードがパチパチ跳ね、フェヌグリークがほんのり色づいたら、すぐに野菜を加える（フェヌグリークの焦がしすぎは苦みの元）。
  3. ターメリック、チリ、塩、砂糖を加えて全体を混ぜ、蓋をして弱火で12〜15分蒸し炒めにする。途中で2回ほど返す。
  4. じゃがいもに竹串がすっと通ったら蓋を外し、中火で水分を飛ばして香ばしく仕上げる。

使い分けのコツ：5種を「同時に」入れるのがベンガル流。ニゲラのほろ苦さとフェンネルの甘さが、野菜の甘みを引き立てます。仕上げにレモンを絞っても爽やかです。

Recipe 06 ・ スープ

タマリンドのラッサム風スープ

約20分 2人分 酸味しっかり

南インドの胡椒スープ「ラッサム」の家庭版。タマリンドの甘酸っぱさと、挽きたてペッパーの辛さが主役です。さらっと飲めるのに、芯のある味に仕上がります。

材料

  • トマト2個
  • タマリンドペースト大さじ1
  • 水500ml
  • にんにく（潰す）1片
  • 油小さじ2
  • マスタードシード小さじ1/2
  • クミンシード小さじ1/2
  • カレーリーフ1枝（約10枚）
  • 乾燥チリ1本
  • ターメリック小さじ1/4
  • ブラックペッパー（粗挽き）小さじ1/2
  • 塩小さじ1/2〜

作り方

  1. トマトはざく切りにする。鍋にトマト、水、ターメリック、タマリンドペースト、塩を入れて中火にかけ、10分ほど煮てトマトを木べらで潰す。
  2. 小さなフライパンに油を熱し、マスタードシード、クミンシード、乾燥チリ、カレーリーフ、にんにくを入れてテンパリングする。マスタードが跳ね終わり、にんにくが香ばしくなったら火を止める。
  3. 香りの油ごとスープへ移し、粗挽きのブラックペッパーを加えてひと煮立ちさせる。味を見て、塩とタマリンドで酸味を調整する。

使い分けのコツ：ラッサムは煮詰めすぎないのがコツ。テンパリングは「後がけ」で香りを立たせ、ペッパーは挽きたてを最後に。タマリンドはブロック派なら、10gほどをぬるま湯で戻してこして使います。

Recipe 07 ・ スープ

トムカー風ココナッツスープ

約20分 2人分 新顔デビュー

新顔ガランガルのデビュー戦。タイの「トムカーガイ」を家庭向けにアレンジした、ココナッツミルクの白いスープです。生姜では出ない、爽やかで突き抜ける香りが主役。ガランガルは香りを出すためのもので、スライス自体は食べずに取り出します。

材料

  • 鶏もも肉150g
  • しめじ（またはふくろ茸）1/2パック
  • ココナッツミルク400ml
  • 水200ml
  • ガランガル（薄切り）5〜6枚
  • レモングラス（あれば）1本
  • こぶみかんの葉（あれば）2枚
  • 乾燥チリ1〜2本
  • ナンプラー大さじ1.5
  • ライム汁（またはレモン汁）大さじ1.5
  • 砂糖小さじ1
  • パクチー（仕上げ）適量

作り方

  1. 鶏肉は一口大に切る。レモングラスは4cm長さに切って包丁の背で叩き、こぶみかんの葉は半分にちぎる。
  2. 鍋に水とココナッツミルク半量を入れ、ガランガル、レモングラス、こぶみかんの葉、乾燥チリを加えて弱火にかける。沸騰させすぎないように5分ほど香りを移す。
  3. 鶏肉としめじ、残りのココナッツミルクを加え、鶏肉に火が通るまで5分ほど煮る。
  4. 火を止めてから、ナンプラー、砂糖、ライム汁を加える。酸味は火を止めてから入れるのが、香りを飛ばさないコツ。
  5. 味を見て塩味と酸味を調整し、器に盛ってパクチーを散らす。ガランガルのスライスは香り付け用なので、食べずによけてOKです。

使い分けのコツ：ガランガルは「生姜の代わり」ではありません。生で手に入らない場合は乾燥スライスを水で戻してもOK。辛さはチリの本数で調整でき、ココナッツの甘みのあとにピリッと来るくらいがバランスのいい仕上がりです。
